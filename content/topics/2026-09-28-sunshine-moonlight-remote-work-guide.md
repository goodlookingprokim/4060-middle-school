# 맥북 하나로 윈도우 PC와 맥미니를 오가는 법

## Sunshine과 Moonlight 실전 세팅 가이드

집에 윈도우 PC와 맥미니가 함께 있는데, 작업할 때마다 자리를 옮기거나 키보드·마우스·모니터를 다시 연결하는 일이 번거로울 때가 있습니다. 특히 맥북을 들고 소파나 침대로 이동했는데, 필요한 파일이나 프로그램은 책상 위 PC에만 설치되어 있으면 다시 일어나야 합니다.

이럴 때 쓸 수 있는 조합이 **Sunshine과 Moonlight**입니다.

이 글은 게임만을 위한 설명이 아닙니다. 윈도우 전용 프로그램, 맥 전용 개발 도구, 집에 있는 파일, 다운로드 작업, 긴 실행 작업을 다른 방의 맥북에서 이어서 하고 싶은 분을 위한 안내입니다.

> 이 글의 설정은 먼저 집 안의 같은 공유기에서 안정적으로 연결하는 것을 기준으로 합니다. 집 밖에서 접속하는 방법은 기본 연결을 확인한 뒤 뒤에서 따로 설명합니다.

## 먼저 결론

- **Sunshine은 화면과 소리를 보내는 호스트**입니다. 윈도우 PC와 맥미니에 설치합니다.
- **Moonlight는 화면을 받아 보고 키보드·마우스를 돌려보내는 클라이언트**입니다. 들고 다니는 맥북 M1에 설치합니다.
- 처음에는 세 기기를 **같은 공유기**에 연결하고, 일꾼 컴퓨터는 가능하면 **랜선**으로 연결합니다.
- 원격 화면이 끊기는 문제보다 먼저 확인할 것은 **컴퓨터 절전, 방화벽, macOS 화면 기록·손쉬운 사용 권한**입니다.
- 집 밖에서 사용할 때는 Sunshine 포트를 인터넷에 직접 열기보다 **Tailscale 같은 사설 네트워크**를 먼저 고려하는 편이 안전합니다.

## 1. 방송국과 리모컨으로 이해하기

Sunshine과 Moonlight의 관계는 방송국과 TV 리모컨의 관계와 비슷합니다.

### Sunshine = 화면을 송출하는 방송국

Sunshine은 컴퓨터의 화면과 소리를 실시간 영상으로 만들어 네트워크로 보냅니다. 문라이트에서 키보드와 마우스로 내린 명령을 받아 실제 프로그램도 실행합니다.

따라서 Sunshine은 다음과 같은 컴퓨터에 설치합니다.

- 계속 켜 두기 쉬운 컴퓨터
- 성능이 좋아 무거운 프로그램을 실행할 컴퓨터
- 책상이나 선반에 고정해 둘 컴퓨터
- 랜선으로 공유기에 연결할 수 있는 컴퓨터

### Moonlight = 화면을 보고 조작하는 TV 겸 리모컨

Moonlight는 Sunshine이 보낸 화면을 받아 보여 줍니다. 내가 누른 키보드·마우스 입력은 다시 Sunshine 쪽 컴퓨터로 보내 줍니다.

따라서 Moonlight는 다음과 같은 기기에 설치하면 편합니다.

- 들고 다니는 맥북이나 노트북
- 화면과 배터리가 좋은 태블릿
- 거실 TV나 휴대용 게임기

중요한 점은 **두 프로그램이 같은 컴퓨터에 설치되는 것이 아니라는 것**입니다. Sunshine은 일을 하는 쪽, Moonlight는 그 일을 원격으로 조작하는 쪽입니다.

## 2. 이 환경에서 권하는 역할 나누기

| 기기 | 맡길 역할 | 설치할 프로그램 | 잘 맞는 일 |
| --- | --- | --- | --- |
| 맥북 M1 | 컨트롤러·클라이언트 | Moonlight | 소파·침대·카페에서 원격 조작 |
| 윈도우 PC | 일꾼 1·호스트 | Sunshine | 윈도우 전용 프로그램, 스팀 게임, 고성능 작업 |
| 맥미니 | 일꾼 2·호스트 | Sunshine | 맥 전용 개발 도구, 다운로드, 장시간 실행 작업 |

이 구조의 장점은 **맥북을 가장 가볍게 유지할 수 있다는 것**입니다. 맥북에 모든 프로그램과 파일을 억지로 설치하지 않고, 필요한 작업이 있는 컴퓨터에 접속해서 사용하면 됩니다.

다만 작업의 성격에 따라 주력 호스트는 달라질 수 있습니다.

- 윈도우 전용 프로그램이나 게임패드를 써야 하는 일은 윈도우 PC가 더 적합합니다.
- 맥미니는 코딩, 터미널, 문서 작업, 다운로드처럼 키보드·마우스 중심의 일에 잘 맞습니다.
- 현재 Sunshine의 기능 표 기준으로 macOS 호스트는 게임패드 에뮬레이션에 제약이 있으므로, 게임패드가 중요한 게임은 윈도우 PC를 우선 호스트로 잡는 편이 좋습니다.

## 3. 설치 전에 먼저 준비할 것

프로그램부터 설치하기보다 네트워크와 전원 설정을 먼저 확인하면 시행착오가 줄어듭니다.

### 같은 공유기에 연결하기

첫 연결은 반드시 맥북, 윈도우 PC, 맥미니를 같은 집 공유기에 연결해 진행합니다.

- 맥북: 5GHz 또는 6GHz Wi-Fi 권장
- 윈도우 PC·맥미니: 가능하면 공유기까지 랜선 연결
- 2.4GHz Wi-Fi: 연결 확인용으로는 가능하지만 화면 스트리밍에는 가급적 피하기

인터넷 속도가 빠른 것만으로 충분하지는 않습니다. 화면 스트리밍은 인터넷 회선 속도보다 **집 안에서 기기와 공유기 사이의 지연시간과 무선 품질**에 더 큰 영향을 받습니다.

### 호스트 컴퓨터가 잠들지 않게 하기

화면만 꺼지는 것은 괜찮지만 컴퓨터 자체가 잠들면 Moonlight가 접속할 수 없습니다.

- 윈도우: 화면 끄기와 PC 절전을 구분해 설정합니다.
- macOS: 디스플레이 끄기와 Mac 잠자기를 구분해 확인합니다.
- 노트북 호스트라면 덮개를 닫았을 때 잠드는지도 따로 확인합니다.

절전을 완전히 끄는 것이 부담스럽다면 우선 테스트 기간에만 잠자기를 막고, 안정적으로 사용하는 방법을 정한 뒤 전력 설정을 다시 조정해도 됩니다.

### 호스트의 이름을 알아보기 쉽게 정하기

Sunshine을 두 대에 설치하면 Moonlight 목록에 컴퓨터가 두 개 나타납니다. 윈도우 PC의 이름을 `Windows-PC`, 맥미니의 이름을 `Mac-mini`처럼 구분해 두면 잘못 접속하는 일이 줄어듭니다.

## 4. 윈도우 PC와 맥미니에 Sunshine 설치하기

Sunshine은 오픈소스 프로젝트인 LizardByte에서 관리합니다. 검색 결과에 보이는 임의의 다운로드 사이트보다 **공식 GitHub 저장소의 Releases**에서 운영체제에 맞는 파일을 받는 편이 안전합니다.

<div class="action-row">
  <a href="https://github.com/LizardByte/Sunshine/releases/latest" target="_blank" rel="noopener">Sunshine 공식 Releases 열기 (외부 사이트 · 새 창)</a>
</div>

### 윈도우 PC

1. 공식 Releases에서 Windows용 설치 파일을 내려받습니다.
2. 설치 프로그램을 실행하고 기본 설치를 진행합니다.
3. Sunshine을 실행합니다.
4. 브라우저에서 `https://localhost:47990`을 엽니다.
5. 처음 나타나는 보안 경고는 내 컴퓨터 안에서 사용하는 자체 서명 인증서 경고입니다. 주소가 정말 `localhost`인지 확인한 뒤 고급 메뉴에서 계속 진행합니다.
6. Sunshine 관리자 화면에서 새 아이디와 비밀번호를 만듭니다.
7. 윈도우 방화벽이 물어보면 개인 네트워크에서 Sunshine이 통신하도록 허용합니다.

공용 Wi-Fi나 인터넷 전체에 허용하는 것이 아니라, 집에서 사용하는 **개인 네트워크**를 기준으로 허용하는 것이 좋습니다.

### 맥미니

1. 공식 Releases에서 macOS용 설치 파일을 내려받습니다.
2. 설치 후 Sunshine을 실행합니다.
3. macOS가 화면 기록, 손쉬운 사용 등 권한을 요청하면 Sunshine이 화면을 캡처하고 키보드·마우스를 전달할 수 있도록 허용합니다.
4. 브라우저에서 `https://localhost:47990`을 열고 관리자 계정을 만듭니다.
5. 권한을 나중에 허용했다면 Sunshine을 종료했다가 다시 실행합니다.

macOS 버전과 Sunshine 버전에 따라 권한 이름이나 요청 시점은 달라질 수 있습니다. 화면은 보이는데 마우스·키보드가 움직이지 않는다면 권한을 다시 확인하는 것이 첫 순서입니다.

### 관리자 페이지 비밀번호는 대충 정하지 않기

Sunshine 관리자 페이지는 연결 설정뿐 아니라 원격 조작과 관련된 중요한 화면입니다.

- 다른 사이트에서 쓰지 않는 비밀번호를 사용합니다.
- `1234`, 생일, 전화번호처럼 추측하기 쉬운 값은 피합니다.
- 관리자 페이지의 `47990` 포트를 인터넷에 그대로 공개하지 않습니다.
- 연결이 끝난 뒤에는 브라우저에 비밀번호를 저장할지 신중하게 판단합니다.

## 5. 맥북 M1에 Moonlight 설치하기

맥북에서는 Moonlight 공식 사이트나 공식 배포 경로에서 macOS 클라이언트를 설치합니다.

<div class="action-row">
  <a href="https://moonlight-stream.org/" target="_blank" rel="noopener">Moonlight 공식 사이트 열기 (외부 사이트 · 새 창)</a>
</div>

1. 맥북용 Moonlight를 내려받습니다.
2. 응용 프로그램(Applications) 폴더에 넣습니다.
3. Moonlight를 실행합니다.
4. 같은 공유기에 연결된 윈도우 PC와 맥미니가 자동으로 검색되는지 확인합니다.

자동으로 보이지 않아도 곧바로 실패라고 판단할 필요는 없습니다. 공유기가 기기 간 검색을 막거나, 호스트 방화벽이 검색 신호를 차단하는 경우가 있습니다. 이때는 Moonlight에서 **컴퓨터를 직접 추가하는 메뉴**를 사용하고 호스트의 내부 IP 주소를 입력합니다.

## 6. 처음 한 번만 하는 페어링

페어링은 “이 맥북이 이 컴퓨터에 접속해도 된다”고 두 기기를 짝지어 주는 절차입니다. 윈도우 PC와 맥미니는 각각 따로 페어링해야 합니다.

1. 맥북 Moonlight에 나타난 윈도우 PC 아이콘을 누릅니다.
2. 맥북 화면에 숫자 PIN이 나타납니다.
3. 윈도우 PC의 Sunshine 관리자 페이지를 엽니다.
4. 페어링 또는 PIN 입력 화면에 맥북의 PIN을 입력합니다.
5. 같은 방법으로 맥미니도 페어링합니다.
6. Moonlight에서 두 호스트의 자물쇠가 풀렸는지 확인합니다.

페어링이 끝난 뒤에는 매번 PIN을 입력하지 않아도 됩니다. 다만 Sunshine을 초기화했거나 Moonlight의 저장 정보를 지웠다면 다시 페어링해야 할 수 있습니다.

## 7. Desktop으로 먼저 테스트하기

처음부터 게임이나 복잡한 프로그램을 실행하지 말고, 두 호스트에 있는 **Desktop** 항목으로 접속하는 것이 좋습니다.

1. Moonlight에서 `Windows-PC`를 선택합니다.
2. `Desktop`을 누릅니다.
3. 윈도우 바탕화면이 맥북에 나타나는지 확인합니다.
4. 메모장을 열어 키보드 입력이 전달되는지 확인합니다.
5. 파일 탐색기를 열어 마우스 클릭이 자연스러운지 확인합니다.
6. 연결을 종료하고 같은 방법으로 `Mac-mini`에 접속합니다.

이 과정을 통과하면 Sunshine과 Moonlight의 기본 연결은 성공한 것입니다. 게임이나 특정 프로그램이 안 되는 문제는 그 다음 단계에서 따로 해결하면 됩니다.

Moonlight의 종료 단축키는 클라이언트와 버전에 따라 조금 다를 수 있습니다. 일반적인 PC 클라이언트에서는 `Ctrl + Alt + Shift + Q`가 사용되지만, 작동하지 않으면 Moonlight 화면의 종료 메뉴나 설정에서 현재 단축키를 확인하세요.

## 8. 화면을 부드럽게 만드는 기본 설정

처음부터 최고 화질로 올리면 원인을 찾기 어려워집니다. 다음처럼 낮은 부담의 설정에서 시작해 한 가지씩 올리는 편이 좋습니다.

### 처음 권하는 시작값

- 해상도: 1920×1080
- 화면 주사율: 60fps
- 비트레이트: 15~25Mbps부터 시작
- 코덱: 호스트와 맥북이 함께 지원하는 하드웨어 코덱 우선
- 오디오: 기본 설정

화면이 안정적이면 비트레이트를 조금씩 올리고, 4K나 120fps는 마지막에 시험합니다. 4K는 화면 정보량이 훨씬 많아 호스트 성능, 맥북, 공유기, Wi-Fi 환경이 모두 받쳐줘야 합니다.

### 끊김과 화질을 구분하기

- **화면이 뭉개진다:** 비트레이트가 낮거나 장면 변화가 많을 수 있습니다.
- **화면이 멈칫한다:** Wi-Fi 간섭, 공유기 지연, 호스트 인코딩 부담을 의심합니다.
- **마우스가 늦게 따라온다:** 네트워크 지연이나 프레임 설정을 확인합니다.
- **소리만 끊긴다:** 오디오 장치 전환, Bluetooth 장치, 호스트의 출력 설정을 확인합니다.

Moonlight의 통계 오버레이를 켜면 네트워크 지연, 프레임 손실, 디코딩 상태를 확인하는 데 도움이 됩니다. 느낌만으로 “컴퓨터가 느리다”고 판단하지 말고, 통계를 보면서 네트워크 문제와 호스트 문제를 나누어 보는 것이 좋습니다.

## 9. 맥미니에 모니터가 없을 때

맥미니를 본체만 켜 둔 채 사용하면 모니터가 연결되지 않은 상태로 인식될 수 있습니다. 그 결과 다음 문제가 생길 수 있습니다.

- 해상도가 낮게 잡힘
- 원하는 화면 비율이 나타나지 않음
- 검은 화면이나 이상한 화면 배치
- 원격 접속할 때마다 해상도가 바뀜

이때는 두 가지 방법이 있습니다.

### 방법 1: HDMI 더미 플러그

맥미니의 HDMI 포트에 작은 가상 모니터 어댑터를 연결해 항상 모니터가 있는 것처럼 인식하게 합니다. 단순하고 안정적이라는 장점이 있습니다.

### 방법 2: 가상 디스플레이

macOS와 별도 도구의 가상 디스플레이 기능을 이용하는 방법입니다. 책상에 어댑터를 꽂기 싫거나 해상도를 자주 바꾸고 싶을 때 유용할 수 있지만, macOS 버전과 도구의 호환성을 확인해야 합니다.

둘 중 하나를 선택하되, 먼저 실제 모니터를 연결한 상태에서 Sunshine 연결이 정상인지 확인한 뒤 무헤드리스 환경으로 바꾸는 것이 안전합니다.

## 10. 집 밖에서 접속할 때의 원칙

같은 집 Wi-Fi에서는 잘 되는데 카페나 다른 지역에서는 자동으로 컴퓨터가 나타나지 않는 것이 정상입니다. 집 안 네트워크와 외부 인터넷은 다른 영역이기 때문입니다.

가장 쉬운 순서는 다음과 같습니다.

1. 윈도우 PC와 맥미니에 Tailscale 같은 사설 네트워크 도구를 설치합니다.
2. 맥북에도 같은 계정 또는 같은 네트워크로 연결합니다.
3. 호스트의 사설 네트워크 IP를 Moonlight에 직접 추가합니다.
4. 먼저 Desktop 연결을 시험합니다.
5. 안정적으로 연결된 뒤에 해상도와 비트레이트를 조정합니다.

Moonlight 공식 안내도 Tailscale, ZeroTier 같은 소프트웨어 기반 네트워크를 집 밖 접속 방법 중 하나로 소개합니다.

반대로 처음부터 공유기에서 Sunshine 관련 포트를 인터넷 전체에 개방하는 방식은 권하지 않습니다. 포트포워딩은 작동할 수 있지만 방화벽, 인증서, 외부 노출, 공유기 설정을 함께 관리해야 하므로 초보자에게는 위험과 관리 부담이 커집니다.

## 11. 자주 막히는 지점과 해결 순서

### 컴퓨터 아이콘이 Moonlight에 나타나지 않는다

1. 세 기기가 같은 공유기에 있는지 확인합니다.
2. 윈도우 방화벽에서 Sunshine을 개인 네트워크에 허용했는지 확인합니다.
3. Sunshine이 실제로 실행 중인지 확인합니다.
4. 호스트의 내부 IP를 확인해 Moonlight에서 직접 추가합니다.
5. 공유기에 ‘무선 사용자 간 통신 차단’, ‘AP isolation’ 같은 기능이 켜져 있는지 확인합니다.

### 페어링은 됐는데 화면이 검다

1. 호스트에 실제 모니터를 잠시 연결해 봅니다.
2. 맥미니라면 HDMI 더미 플러그나 가상 디스플레이를 확인합니다.
3. macOS의 화면 기록 권한을 확인합니다.
4. 호스트가 잠금 화면이나 절전 상태인지 확인합니다.
5. Sunshine과 Moonlight를 모두 최신 안정 버전으로 맞춥니다.

### 화면은 보이는데 키보드·마우스가 움직이지 않는다

1. macOS의 손쉬운 사용 권한에서 Sunshine을 허용합니다.
2. 화면 기록 권한도 함께 확인합니다.
3. Sunshine을 완전히 종료했다가 다시 실행합니다.
4. 맥북의 특수키나 한영키가 원격 호스트에서 어떻게 전달되는지 확인합니다.

### 화면이 끊기고 지연이 느껴진다

1. 호스트를 랜선으로 연결합니다.
2. 맥북을 5GHz 또는 6GHz에 연결합니다.
3. 비트레이트를 낮춰 봅니다.
4. 4K·120fps를 1080p·60fps로 낮춰 비교합니다.
5. Moonlight 통계에서 네트워크 지연과 프레임 손실을 확인합니다.

### 맥미니와 윈도우 PC를 헷갈린다

Sunshine의 컴퓨터 이름을 구분하고, Moonlight에서도 이름을 바꿔 둡니다. 연결하기 전에 “지금 어느 컴퓨터에 들어가는가?”를 확인하는 습관은 파일을 잘못 수정하거나 종료하는 실수를 줄여 줍니다.

## 12. 가장 안전한 설치·검증 순서

한 번에 모든 기능을 설정하지 말고 아래 순서로 진행하면 문제가 생겨도 원인을 좁히기 쉽습니다.

```text
1. 세 기기를 같은 공유기에 연결
   ↓
2. 윈도우 PC에 Sunshine 설치
   ↓
3. 맥북 Moonlight에서 윈도우 PC 페어링
   ↓
4. Desktop으로 화면·키보드·마우스 확인
   ↓
5. 맥미니에도 Sunshine 설치
   ↓
6. macOS 권한과 모니터 없는 환경 확인
   ↓
7. 맥미니 페어링 후 Desktop 테스트
   ↓
8. 1080p·60fps에서 지연과 끊김 확인
   ↓
9. 필요할 때만 4K·고비트레이트·집 밖 접속 추가
```

첫날부터 집 밖 접속, 4K, 게임패드, 가상 디스플레이를 모두 시도하면 어느 단계에서 문제가 생겼는지 알기 어렵습니다. **작은 성공을 먼저 만든 뒤 기능을 하나씩 더하는 방식**이 가장 빠릅니다.

## 남겨둘 판단

Sunshine과 Moonlight의 핵심은 “어디서든 모든 일을 한다”는 마법이 아닙니다. **일을 잘하는 컴퓨터와, 들고 다니기 좋은 컴퓨터의 역할을 나누는 것**입니다.

맥북 M1을 화면과 리모컨으로 두면 가벼운 기기를 계속 들고 다닐 수 있고, 윈도우 PC와 맥미니는 각자 잘하는 일을 맡길 수 있습니다. 특히 집 안에서 먼저 1080p·60fps로 연결을 확인하고, 호스트를 랜선에 연결하고, 잠자기와 권한을 정리하는 세 가지만 해도 체감 품질이 크게 달라집니다.

처음부터 최고의 화질을 목표로 하기보다 다음 세 문장을 기준으로 환경을 잡아 보세요.

> **화면을 보내는 컴퓨터는 깨어 있고 유선으로 연결한다.**
>
> **화면을 받는 맥북은 좋은 Wi-Fi에 연결한다.**
>
> **새 기능은 Desktop 연결이 안정된 뒤 하나씩 추가한다.**
