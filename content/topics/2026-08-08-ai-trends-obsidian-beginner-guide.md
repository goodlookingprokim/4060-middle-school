# AI 자료가 너무 많아 겁난다면, 옵시디언으로 어디서부터 붙들면 좋을까

출처와 감사

- 학습팩 원문: `최근 AI·기술 동향 학습 큐레이션 40`  
  이 글은 2026년 8월 8일 기준으로 정리된 LilysAI 최근 40개 노트 학습팩을 바탕으로 다시 풀어 쓴 글입니다.
- 공개 요약 링크는 원문 작성자가 열어 둔 LilysAI 공개 링크를 따라갑니다.
- 원문 안의 기사, 유튜브, GitHub, 공식 문서 링크는 각 항목마다 함께 남겼습니다.

옵시디언을 써보고 싶다는 말은 많이 듣는데, 막상 시작은 잘 안 됩니다.

- 폴더를 어떻게 나눠야 할지 모르겠고
- 자료를 넣기 시작하면 금방 복잡해질 것 같고
- AI 관련 링크를 모아두기만 하다가 더 지칠 것 같기 때문입니다

이번 글은 바로 그 지점에서 시작합니다. 첨부된 40개 학습 자료를 “다 읽어야 하는 숙제”로 보지 않고, **옵시디언을 아직 무서워하는 사람도 오늘 바로 첫 메모를 남길 수 있게** 다시 정리해 보려 합니다.

## 먼저 결론

- 옵시디언은 많이 아는 사람이 쓰는 도구가 아니라, **많아서 무서운 자료를 조금씩 정리하려는 사람**에게 더 잘 맞습니다.
- 이번 40개 자료를 한 번에 다 읽지 말고, **읽는 이유에 따라 3갈래로 나눠** 붙들면 훨씬 덜 겁납니다.
- 처음부터 예쁘게 꾸미기보다, **한 줄 요약 노트 3개만 만들어도** 옵시디언은 바로 쓸모가 생깁니다.

## 상황

이번에 받은 학습팩은 최근 AI·기술 동향 40개를 교사, 연구자, AI 도구 사용자 기준으로 묶어 둔 자료였습니다.

좋은 점은 분명했습니다.

- 원본 링크가 있고
- 공개 요약 링크가 같이 있고
- 교육, 에이전트, 업무, 도구, 디자인 흐름이 한눈에 모여 있었습니다

그런데 바로 여기서 초보자는 자주 멈춥니다.

“좋은 자료가 많다”는 말은, 뒤집으면 “어디서부터 읽어야 할지 모르겠다”는 뜻이 되기 쉽기 때문입니다.

특히 옵시디언을 쓰고 싶지만 아직 익숙하지 않은 분은, 이런 학습팩을 보면 오히려 더 손을 못 대는 경우가 많습니다.

그래서 이번 글은 40개 전체를 다시 나열하기보다, **이 자료를 옵시디언에 어떻게 받아 적으면 덜 무섭고 더 오래 남는지** 중심으로 풀겠습니다.

## 왜 옵시디언이 여기서 도움이 될까

옵시디언의 장점은 “멋진 제2의 뇌” 같은 거창한 말보다, 훨씬 단순한 데 있습니다.

> 읽은 자료를 한곳에 남기고, 다음에 다시 꺼내볼 때 덜 막막하게 해 준다.

이번 같은 학습팩에서는 이게 특히 중요합니다.

링크가 40개면 읽는 순간보다, **이틀 뒤에 무엇을 다시 꺼낼 수 있느냐**가 더 중요해집니다.

예를 들어 이런 식입니다.

- “옵시디언 플러그인 관련 영상이 하나 있었지”
- “AI 회사 세팅 자료는 업무용으로 다시 보고 싶다”
- “수업 설계에 바로 쓸 도구는 따로 모아 두자”

이런 걸 머리로만 붙잡고 있으면 금방 섞입니다. 옵시디언은 이 섞임을 줄여 주는 쪽에 강합니다.

## 이번 40개 자료는 크게 세 덩어리로 보면 된다

원문은 항목이 많지만, 처음 보는 분은 아래 세 묶음으로만 잡아도 충분합니다.

### 1. 왜 배워야 하는가

이 묶음은 “AI 시대에 내가 무엇을 더 길러야 하나”를 묻는 자료들입니다.

먼저 보면 좋은 예시는 이런 것들입니다.

- `AI 시대에 컴공은 주산 배우는 셈… 차라리 취업 잘 되는 철학과로`
- `도구에 미쳐버린 사람들, Warp부터 Orca, Paseo까지`
- `New ways to learn and teach with ChatGPT Work and Codex`

이 자료들은 새 도구 설명보다, **앞으로 무엇을 배우는 태도가 더 중요한가**를 잡아줍니다.

### 2. AI가 실제로 일하는 구조

이 묶음은 요즘 AI가 그냥 대답만 하는 게 아니라, 어떻게 연결되고 실행되는지를 보여줍니다.

- Claude Code Skill library
- Ori Harness
- Paseo
- DevSpace
- Ironcode
- GitHub MCP 서버

이런 자료를 보면 “도구 하나를 더 쓴다”보다, **AI에게 일을 맡기는 구조를 어떻게 만든다**는 쪽으로 시야가 넓어집니다.

### 3. 내 일에 바로 붙는 도구

이 묶음은 지금 당장 생활과 업무에 붙일 수 있는 자료들입니다.

- OfficeCLI
- 2026년 유용한 옵시디언 잔기술 모음
- 옵시디언 플러그인, 이거 하나면 됩니다
- Lesson Total Package
- Worksheet-Grab
- Korean Writing Reviewer

처음 시작하는 분은 사실 이 셋 중 **세 번째 묶음부터** 보는 편이 훨씬 낫습니다.

## 옵시디언이 두려운 사람은 이렇게 읽으면 된다

자료가 많을수록 다 읽으려 하지 말고, 읽는 이유를 먼저 정하면 좋습니다.

### A. “나는 아직 AI 전체 흐름이 헷갈린다”

그러면 먼저 아래 3개만 보면 됩니다.

1. `도구에 미쳐버린 사람들, Warp부터 Orca, Paseo까지`
2. `AI 시대에 컴공은 주산 배우는 셈…`
3. `ChatGPT Work and Codex 교육 관련 OpenAI 글`

이 세 개는 기술보다 **방향 감각**을 주는 자료입니다.

### B. “나는 업무에 붙일 수 있는 것부터 보고 싶다”

그러면 아래 4개가 좋습니다.

1. `MS 스킬 레코더 무료 공개`
2. `OfficeCLI`
3. `Korean Writing Reviewer`
4. `AI 회사 세팅 가이드`

이 네 개는 “좋아 보이는 기술”보다 **실제 일을 줄이는 흐름**에 가깝습니다.

### C. “나는 옵시디언이 진짜 무서운데, 그래도 써보고 싶다”

그러면 아래 순서가 좋습니다.

1. `2026년 유용한 옵시디언 잔기술 모음`
2. `옵시디언 플러그인, 이거 하나면 됩니다`
3. [옵시디언 하나를 AI 공용 작업실로 바꾸는 법](./2026-05-31-obsidian-ai-wiki-setup-guide.md)
4. [Graphify와 Obsidian을 같이 쓰면, Claude Code가 왜 같은 질문에 덜 헤매게 될까](./2026-07-23-graphify-obsidian-claude-code-guide.md)

이 순서가 좋은 이유는, 처음 두 개는 “손에 익는 작은 기능”이고, 뒤의 두 개는 “옵시디언을 왜 계속 쓰게 되는가”를 보여주기 때문입니다.

## 처음부터 예쁘게 꾸미지 말고, 이 노트 3개만 만들자

옵시디언이 무서운 가장 큰 이유 중 하나는 처음부터 구조를 완벽히 잡으려 하기 때문입니다.

하지만 이번 학습팩처럼 자료가 많은 경우에는 아래 3개만 있어도 시작이 됩니다.

### 1. `오늘 먼저 볼 것`

여기에는 오늘 읽을 링크 3개만 적습니다.

```markdown
# 오늘 먼저 볼 것

- 도구에 미쳐버린 사람들
- 옵시디언 잔기술 모음
- Korean Writing Reviewer
```

### 2. `읽고 남긴 한 줄`

긴 요약 말고, 자료 하나당 한 줄만 적습니다.

```markdown
# 읽고 남긴 한 줄

- 도구 FOMO보다 터미널과 문제 정의가 먼저다.
- 옵시디언은 예쁘게 꾸미는 도구보다 다시 꺼내보는 도구에 가깝다.
- 한국어 글쓰기 리뷰는 AI 상투 문체를 줄이는 데 바로 써볼 만하다.
```

### 3. `나중에 써먹을 것`

이 노트는 “언젠가 다시 볼 자료”를 모읍니다.

```markdown
# 나중에 써먹을 것

- 수업 설계: Lesson Total Package
- 문서 자동화: OfficeCLI
- 조직 운영: AI 회사 세팅 가이드
```

이 정도만 만들어도, 링크를 저장만 해두고 잊어버리는 패턴에서 조금 벗어날 수 있습니다.

## 이번 학습팩으로 바로 만들어 볼 옵시디언 폴더 구조

처음부터 복잡하게 나누지 않아도 됩니다. 아래 정도면 충분합니다.

```text
AI-학습/
  00-오늘볼것.md
  01-읽고남긴한줄.md
  02-나중에써먹을것.md
  links/
  notes/
```

그리고 `links/`에는 원본 링크나 요약 링크를 모으고, `notes/`에는 읽고 난 뒤 한 줄이나 짧은 메모를 남기면 됩니다.

핵심은 멋진 구조가 아니라, **다음 주에도 내가 다시 찾을 수 있는가**입니다.

## 이 학습팩에서 옵시디언 초보가 특히 챙기면 좋은 자료

이번 40개 중에서, 옵시디언이 아직 낯선 분에게 특히 추천하고 싶은 자료는 아래 여섯 개입니다.

### 1. 2026년 유용한 옵시디언 잔기술 모음

옵시디언이 거창한 철학보다, 실제로 얼마나 편해질 수 있는지 보여주는 자료입니다. 작은 편의 기능이 쌓이면 왜 계속 쓰게 되는지 감이 옵니다.

- 원본: <https://www.youtube.com/watch?v=NKOy5A2EtiQ>
- 공개 요약: <https://lilys.ai/digest/10820836/12707641?s=1&noteVersionId=9295028>

### 2. 옵시디언 플러그인, 이거 하나면 됩니다

플러그인을 많이 깔아야 할 것 같아 겁나는 분에게 특히 좋습니다. “많이 깔기”가 아니라 “덜 복잡하게 쓰기” 쪽으로 보게 해 줍니다.

- 원본: <https://www.youtube.com/watch?v=nvMt3S-URhQ>
- 공개 요약: <https://lilys.ai/digest/10820661/12707419?s=1&noteVersionId=9294802>

### 3. MS 스킬 레코더 무료 공개

내가 하던 화면 작업을 자동화 스킬로 바꿀 수 있다는 발상이, 옵시디언 메모 습관과도 잘 맞습니다. “기록이 곧 절차가 된다”는 감각을 주기 때문입니다.

- 원본: <https://effettoblog.com/blog/ms-스킬-레코더-무료-공개/>
- 공개 요약: <https://lilys.ai/digest/10855273/12757723?s=1&noteVersionId=9346206>

### 4. OfficeCLI

문서를 코드처럼 다루는 흐름을 보여주는 자료입니다. 메모와 문서 작업이 따로가 아니라 연결될 수 있다는 점을 느끼게 해 줍니다.

- 원본: <https://shconsulting.ai/insights/officecli-install>
- 공개 요약: <https://lilys.ai/digest/10838981/12732987?s=1&noteVersionId=9320926>
- 같이 보면 좋은 글: [officecli는 오피스 문서를 코드처럼 다루고 싶을 때 어디까지 쓸 만할까](./2026-08-06-officecli-install-review-guide.md)

### 5. Korean Writing Reviewer

옵시디언에 쌓인 초안 메모를 더 자연스러운 한국어로 손보는 데 바로 연결될 수 있는 자료입니다.

- 원본: <https://github.com/CreatoonForge/korean-writing-reviewer>
- 공개 요약: <https://lilys.ai/digest/10794189/12671323?s=1&noteVersionId=9257631>

### 6. Lesson Total Package

교사나 교육 관련 일을 하는 분에게는 “메모를 수업 설계로 옮기는 흐름”을 생각하게 해 주는 자료입니다.

- 원본: <https://github.com/newskool4d-sketch/lesson-total-package>
- 공개 요약: <https://lilys.ai/digest/10794743/12672188?s=1&noteVersionId=9258516>

## 읽고 나서 옵시디언에 남기면 좋은 질문

자료를 보고도 메모가 안 남는 가장 큰 이유는, 무엇을 적어야 할지 모르기 때문입니다.

그래서 아래 질문만 붙여도 충분합니다.

- 이 자료는 결국 내 시간을 어디서 줄여 주나?
- 이 자료는 혼자 쓰는 도구인가, 같이 쓰는 구조인가?
- 지금 내 일에 붙는가, 아니면 나중에 공부할 거리인가?
- 이걸 한 문장으로 남기면 뭐라고 적을까?

옵시디언 초보는 긴 요약보다 이 질문에 짧게 답하는 편이 더 오래 갑니다.

## 막혔던 지점

> 이번 학습팩의 어려움은 자료 수준이 높아서라기보다, 좋은 자료가 너무 많아 시작점을 잃기 쉽다는 데 있었습니다.

그래서 이 글에서는 40개를 모두 평평하게 소개하지 않고, 읽는 이유와 메모 방법을 먼저 세웠습니다. 옵시디언이 두려운 분에게는 이 순서가 더 중요합니다.

“어디에 저장할까”보다 먼저,
“왜 이걸 읽고 남기나”
가 잡혀야 하기 때문입니다.

## 남겨둘 판단

옵시디언은 정리를 잘하는 사람만 쓰는 도구가 아닙니다. 오히려 자료가 많아질수록 겁부터 나는 사람에게 더 필요할 수 있습니다.

이번 40개 학습팩도 마찬가지입니다. 전부 이해한 뒤 시작하는 것이 아니라, **세 개만 고르고, 한 줄만 남기고, 다시 찾을 수 있게 두는 것**부터 시작하면 됩니다. 그 정도만 해도 옵시디언은 더 이상 “어려운 앱”이 아니라, 내 공부가 흩어지지 않게 붙잡아 주는 작은 작업대가 됩니다.
