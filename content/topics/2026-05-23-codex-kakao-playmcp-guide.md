# 2026년 5월 23일(토) Codex에서 Kakao PlayMCP 설치부터 카카오톡 활용까지

이번 글은 4060미들스쿨 멤버들이 많이 헷갈릴 수 있는 두 가지를 한 번에 정리하려고 썼습니다.

하나는 <strong>Kakao PlayMCP를 Codex에 MCP 서버로 연결하는 일</strong>이고,
다른 하나는 <strong>Codex의 Computer Use로 카카오톡 데스크톱 앱 화면을 직접 조작하는 일</strong>입니다.

겉으로 보면 둘 다 "AI로 카카오톡을 다루는 것"처럼 보이지만, 실제로는 성격이 꽤 다릅니다.

그래서 이번 글은 설치 자체보다 먼저,
<strong>무엇이 원격 MCP이고 무엇이 화면 조작인지</strong>를 분명히 구분하는 데서 시작합니다.

## 먼저 한 줄로 정리하면

```text
Kakao PlayMCP는 Codex에 연결하는 원격 MCP 서버이고,
KakaoTalk Computer Use는 Codex가 카카오톡 앱 화면을 직접 보고 클릭하고 입력하는 기능입니다.
```

이 차이를 먼저 잡아두면, 이후 실습에서 훨씬 덜 헷갈립니다.

## 1. 이번 강의의 목표

이번 시간 목표는 단순히 설치를 끝내는 것이 아닙니다.

- Codex에 `https://playmcp.kakao.com/mcp`를 MCP 서버로 추가해 보기
- PlayMCP 방식과 카카오톡 화면 조작 방식을 구분하기
- 실제 메시지를 바로 보내지 않고, <strong>초안 작성 → 사람 확인 → 전송</strong> 흐름을 익히기
- 4060미들스쿨에서 안전하게 보여줄 수 있는 실습 범위를 정리하기

즉, "된다"를 넘어서 <strong>어디까지 맡기고 어디서 멈춰야 하는지 감각을 익히는 시간</strong>입니다.

## 2. Kakao PlayMCP와 Computer Use는 어떻게 다른가

### Kakao PlayMCP
Kakao PlayMCP는 카카오가 제공하는 MCP 기반 플랫폼입니다.
Codex에 `https://playmcp.kakao.com/mcp`를 원격 MCP 서버로 추가하면, PlayMCP 도구함에 들어 있는 카카오 관련 도구를 사용할 수 있습니다.

흐름은 대략 이렇습니다.

```text
사용자 요청
→ Codex
→ kakao_playmcp MCP 서버
→ PlayMCP 도구함 / 카카오 인증
→ 등록된 도구 실행
```

즉, 이쪽은 <strong>도구를 서버처럼 연결하는 방식</strong>입니다.

### KakaoTalk Computer Use
이쪽은 완전히 다릅니다.
Codex가 컴퓨터 화면을 보고,
카카오톡 데스크톱 앱을 사람이 쓰듯 클릭하고 입력하는 방식입니다.

흐름은 이렇습니다.

```text
사용자 요청
→ Codex
→ Computer Use 플러그인
→ macOS 화면 인식
→ 카카오톡 앱 클릭, 검색, 입력
```

즉, 이쪽은 <strong>카카오톡 공식 API를 부르는 방식이 아니라, 화면을 보고 앱을 직접 조작하는 방식</strong>입니다.

## 3. 왜 이 둘을 분리해서 설명해야 할까

처음 배우는 분은 보통 이렇게 느낍니다.

- 둘 다 카카오톡을 다루는 것 같은데요?
- 둘 다 비슷한 거 아닌가요?

그런데 실제로는 다릅니다.

| 구분 | 연결 대상 | 하는 일의 성격 |
| --- | --- | --- |
| Kakao PlayMCP | `https://playmcp.kakao.com/mcp` 원격 MCP 서버 | 도구함에 담긴 도구를 Codex에서 호출 |
| KakaoTalk Computer Use | 카카오톡 데스크톱 앱 화면 | 클릭, 입력, 검색 같은 화면 조작 |
| 카카오톡 공식 API | 별도의 개발자 API | 서버 기능 직접 연동 |

강의에서는 이 구분을 먼저 말해줘야 참가자들이 뒤에서 덜 꼬입니다.

## 4. 실습 전에 필요한 것

처음 실습할 때는 다섯 가지만 준비하면 됩니다.

### 1) Codex 앱
Codex 앱이 설치돼 있고 로그인되어 있어야 합니다.

### 2) Kakao PlayMCP 원격 MCP 서버
Codex에 아래 주소를 MCP 서버로 추가합니다.

```text
https://playmcp.kakao.com/mcp
```

권장 이름은 아래처럼 잡으면 관리가 쉽습니다.

```text
kakao_playmcp
```

### 3) Computer Use 플러그인
카카오톡 앱 화면을 직접 다루려면 Codex 앱에서 Computer Use를 설치하고 켜야 합니다.

일반적으로는 이런 흐름입니다.

```text
Codex 앱
→ Settings
→ Computer Use
→ Install 또는 Enable
```

### 4) 카카오톡 데스크톱 앱
실습은 macOS 기준으로 준비하는 편이 가장 안전합니다.

강의에서는 실제 단체방보다
- `나와의 채팅`
- 실습용 테스트방
정도로 한정하는 것이 좋습니다.

### 5) macOS 권한 허용
Computer Use는 화면을 봐야 하고 클릭도 해야 하므로 권한이 필요합니다.

필수 권한은 보통 아래 두 가지입니다.

- 화면 기록
- 손쉬운 사용

## 5. 설치 순서

### 단계 1. Kakao PlayMCP 원격 MCP 추가
CLI를 쓸 수 있다면 대략 아래처럼 추가할 수 있습니다.

```bash
codex mcp add kakao_playmcp --url https://playmcp.kakao.com/mcp
```

앱 설정 화면에서 직접 넣는다면 보통 아래 값을 봅니다.

- 이름: `kakao_playmcp`
- URL: `https://playmcp.kakao.com/mcp`
- transport: `streamable_http`
- 상태: enabled

설치 후에는 현재 세션에 바로 안 보일 수 있습니다.
이럴 때는 <strong>새 Codex 세션을 열거나 앱을 재시작</strong>하는 편이 빠릅니다.

### 단계 2. PlayMCP 도구함 인증
이 단계는 "서버 주소를 등록했다"에서 끝나지 않습니다.
실제로는
- PlayMCP 로그인
- 도구함 선택
- 카카오 계정 인증
이 이어져야 실제 도구가 보일 수 있습니다.

즉, 이 단계에서 중요한 건 "주소는 붙였는데 왜 아무 도구가 안 보이지?"를 당황하지 않는 것입니다.

### 단계 3. Codex 앱 로그인 및 기본 확인
Codex 앱에 로그인하고,
MCP 서버와 Computer Use가 현재 세션에서 보이는지 확인합니다.

### 단계 4. 카카오톡 데스크톱 설치와 로그인
카카오톡을 설치하고 로그인합니다.
테스트용 채팅방도 미리 준비해 둡니다.

강의에서는 실제 단체방보다
<strong>나와의 채팅 또는 실습용 단체방</strong>이 훨씬 안전합니다.

### 단계 5. Computer Use 활성화
Codex 설정 안에서 Computer Use를 설치하거나 활성화합니다.
필요하면 macOS 권한 요청도 허용합니다.

### 단계 6. 카카오톡이 인식되는지 확인
카카오톡 앱을 먼저 열어 둔 뒤,
Codex에서 앱 선택 대상에 `KakaoTalk` 또는 비슷한 항목이 뜨는지 확인합니다.

표시 이름은 버전마다 조금 다를 수 있습니다.

## 6. 첫 실습은 이렇게 나누는 것이 좋습니다

처음에는 <strong>PlayMCP 연결 확인</strong>과 <strong>카카오톡 화면 조작 확인</strong>을 섞지 않는 편이 좋습니다.

그리고 더 중요한 원칙이 하나 있습니다.

<strong>처음부터 실제 전송을 바로 시키지 말고, 초안만 작성하게 해야 합니다.</strong>

### 실습 0. PlayMCP 연결 확인
예:

```text
kakao_playmcp MCP 서버가 현재 세션에서 사용 가능한지 확인해 주세요.
가능하다면 어떤 도구를 쓸 수 있는지 초보자도 이해할 수 있게 설명해 주세요.
```

### 실습 1. 카카오톡 앱 열기 확인
예:

```text
@KakaoTalk 카카오톡 앱이 열려 있는지 확인하고, 현재 보이는 화면을 간단히 설명해 주세요.
```

### 실습 2. 읽지 않은 대화방 확인
예:

```text
@KakaoTalk 읽지 않은 대화방이 있는지 확인해 주세요. 메시지 내용은 열지 말고 대화방 이름만 알려 주세요.
```

### 실습 3. 테스트 채팅방에 초안만 입력
예:

```text
@KakaoTalk '나와의 채팅'을 열고 아래 문장을 입력창에 초안으로만 넣어 주세요. 아직 전송하지 마세요.

안녕하세요. Codex Computer Use 실습 메시지입니다.
```

### 실습 4. 전송 전 확인 후 보내기
이 단계는 사용자가 명확히 확인한 뒤에만 갑니다.

```text
@KakaoTalk 지금 입력창에 있는 테스트 메시지를 나와의 채팅에 전송해 주세요.
```

## 7. 강의에서 보여주기 좋은 활용 예시

### 예시 1. PlayMCP 도구함 확인
```text
kakao_playmcp에서 지금 쓸 수 있는 도구가 무엇인지 확인하고,
각 도구로 할 수 있는 일을 쉬운 한국어로 설명해 주세요.
```

이 예시는 참가자에게 "MCP가 붙으면 이런 도구들이 열린다"는 감각을 주기 좋습니다.

### 예시 2. 나와의 채팅방 사용 가능 여부 확인
```text
kakao_playmcp 도구 중 카카오톡 나와의 채팅방과 관련된 도구가 있는지 확인해 주세요.
있다면 어떤 식으로 요청해야 하는지 예시 프롬프트를 만들어 주세요.
```

이 예시는 PlayMCP 방식과 화면 조작 방식 차이를 설명할 때 좋습니다.

### 예시 3. 최근 메시지 요약
```text
@KakaoTalk 실습방의 최근 메시지를 읽고 핵심 내용을 3줄로 요약해 주세요.
```

이건 단체방 공지 요약 시연으로 쓰기 좋지만,
민감한 방에서는 하지 않는 것이 맞습니다.

### 예시 4. 답장 초안 만들기
```text
@KakaoTalk 실습방의 마지막 메시지에 대해 정중한 답장 초안을 작성해 주세요. 전송하지 말고 입력창에만 넣어 주세요.
```

이건 가장 실용적인 시연 중 하나입니다.

### 예시 5. 특정 단어 검색
```text
@KakaoTalk 현재 채팅방에서 '준비물'이라는 단어가 들어간 최근 메시지를 찾아 요약해 주세요.
```

이건 실제 운영방에서 자료 찾기, 날짜 찾기, 준비물 찾기 예시로 아주 좋습니다.

### 예시 6. 공지문 Markdown 정리
```text
@KakaoTalk 실습방의 최근 공지 내용을 복사해서 제목, 날짜, 준비물, 할 일 순서의 Markdown으로 정리해 주세요.
```

이건 공지 정리, 회의록 초안 만들기 예시로 좋습니다.

## 8. PlayMCP와 Computer Use를 섞어 설명하지 않기
이 부분이 강의에서 정말 중요합니다.

참가자 입장에서는 둘 다 "카카오톡을 다루는 AI"처럼 보이기 쉽습니다.
하지만 강의에서는 이렇게 잘라 말하는 게 좋습니다.

- PlayMCP = 카카오 도구함을 Codex에 연결하는 것
- Computer Use = 카카오톡 앱 화면을 직접 조작하는 것

즉,
<strong>서버 연결과 화면 조작은 다르다</strong>는 걸 계속 분리해서 말해줘야 합니다.

## 9. 좋은 프롬프트는 어떻게 생겼나
Computer Use는 화면을 직접 다루기 때문에 프롬프트를 모호하게 쓰면 금방 위험해집니다.

좋은 프롬프트는 보통 아래를 포함합니다.

- 어떤 앱을 쓸지
- 어떤 방을 열지
- 읽기만 할지, 입력만 할지, 전송까지 할지
- 민감 정보가 보이면 멈출지
- 마지막 전송 전에 확인을 받을지

예를 들면 이런 문장이 좋습니다.

```text
전송하지 말고 초안만 작성해 주세요.
민감한 개인정보가 보이면 내용을 읽지 말고 멈춰 주세요.
마지막 전송 버튼을 누르기 전에 제 확인을 받아 주세요.
현재 화면에서 보이는 범위 안에서만 작업해 주세요.
```

반대로 이런 식은 피하는 게 좋습니다.

```text
알아서 다 처리해 줘.
모든 단톡방에 보내 줘.
최근 대화를 전부 읽고 정리해 줘.
```

이런 문장은 범위가 너무 넓고, 사고가 나기 쉽습니다.

## 11. 자주 막히는 지점

### 1) `kakao_playmcp`가 안 보일 때
- URL이 맞는지
- 이름이 맞는지
- 새 세션을 열었는지
- PlayMCP 인증이 필요한지
를 먼저 봅니다.

### 2) PlayMCP 주소를 브라우저에서 열었는데 안 보일 때
이 주소는 일반 웹페이지처럼 읽는 주소라기보다,
Codex 같은 MCP 클라이언트에 등록하는 서버 주소로 이해하는 편이 맞습니다.

### 3) `@KakaoTalk`이 안 보일 때
- 카카오톡 앱을 먼저 열기
- Codex 재시작
- Computer Use 설치 확인
- 화면 기록 / 손쉬운 사용 권한 확인

### 4) Codex가 화면을 못 볼 때
보통은 화면 기록 권한 문제일 가능성이 큽니다.

### 5) 화면은 보는데 입력을 못 할 때
보통은 손쉬운 사용 권한 문제일 가능성이 큽니다.

### 6) 엉뚱한 채팅방을 열었을 때
이럴 때는 즉시

```text
멈춰 주세요. 아무것도 입력하거나 전송하지 마세요.
```

라고 하는 쪽이 안전합니다.

### 7) 메시지를 잘못 보낼까 걱정될 때
처음부터 아래 문장을 붙이는 것이 좋습니다.

```text
전송 버튼은 절대 누르지 말고, 입력창에 초안만 작성해 주세요.
```

## 12. 강의에서 꼭 남겨야 할 말
마지막에 이 말은 꼭 남기면 좋습니다.

```text
AI가 카카오톡을 대신 써 줄 수는 있지만,
관계와 책임은 사람이 끝까지 확인해야 합니다.
```

이 문장이 이번 강의의 핵심입니다.

AI가 도와줄 수 있는 범위는 넓어졌지만,
전송, 공유, 삭제처럼 다른 사람에게 영향을 주는 일은
여전히 사람이 마지막에 확인해야 합니다.

## 마무리

이번 글은 Kakao PlayMCP와 Computer Use를 한 번에 다루지만,
실제 강의에서는 처음부터 다 시키기보다 아래 순서가 좋습니다.

1. MCP 연결 확인
2. 어떤 도구가 보이는지 확인
3. 카카오톡 앱 화면 인식 확인
4. 초안만 작성
5. 마지막에만 전송

즉, <strong>설치보다 먼저 구분</strong>,
<strong>전송보다 먼저 초안</strong>,
<strong>자동화보다 먼저 확인</strong>이 이번 실습의 기준입니다.

이 기준만 잡히면, 참가자들이 "와, 된다"에서 끝나는 게 아니라
"이건 우리 일에도 조심해서 붙여볼 수 있겠다" 쪽으로 넘어가기 쉬워집니다.
