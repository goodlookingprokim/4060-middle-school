# 2026년 5월 23일(토) Codex에서 Kakao PlayMCP 설치부터 카카오톡 활용까지

처음 Codex로 카카오 쪽 기능을 만져보면, 문 앞이 두 개 열려 있는 느낌이 듭니다.
둘 다 비슷한 곳으로 들어가는 것처럼 보이는데, 막상 몇 걸음 들어가 보면 길의 성격이 다릅니다.

겉으로 보면 둘 다 "카카오톡을 AI로 다룬다"는 이야기처럼 보이지만, 실제로는 서로 다른 두 기능이 함께 등장합니다.

- <strong>Kakao PlayMCP 원격 MCP 추가</strong>
- <strong>KakaoTalk Computer Use</strong>

그래서 이번 글의 핵심은 단순 설치가 아니라, <strong>무엇이 PlayMCP이고 무엇이 Computer Use인지 차분히 떼어 놓고 보는 일</strong>입니다. 이 차이만 또렷해져도, 뒤의 실습은 훨씬 편안해집니다.

## 1. 한 줄로 이해하기

먼저 이 한 문장부터 잡고 가면 됩니다.

> Kakao PlayMCP는 Codex에 연결하는 원격 MCP 서버이고, KakaoTalk Computer Use는 Codex가 카카오톡 데스크톱 앱 화면을 직접 조작하는 기능입니다.

이 차이를 먼저 이해하면 뒤의 설치와 실습이 훨씬 덜 꼬입니다.

### Kakao PlayMCP 흐름

```text
사용자 요청
→ Codex
→ kakao_playmcp MCP 서버
→ PlayMCP 도구함 / 카카오 계정 인증
→ PlayMCP에 등록된 도구 실행
```

### KakaoTalk Computer Use 흐름

```text
사용자 요청
→ Codex
→ Computer Use 플러그인
→ macOS 화면 인식
→ 카카오톡 데스크톱 앱 클릭, 검색, 입력
```

## 2. MCP와 Computer Use는 무엇이 다른가

### MCP는 무엇인가요?
MCP는 AI가 외부 도구와 연결될 수 있게 해주는 표준적인 연결 방식입니다. 파일, 브라우저, 앱, 데이터베이스처럼 바깥에 있는 도구를 AI가 다룰 때 중간 통로 역할을 해준다고 보면 됩니다.

### Computer Use는 무엇인가요?
Computer Use는 Codex가 컴퓨터 화면을 보고 직접 앱을 조작하게 해주는 기능입니다. 쉽게 말하면, 사람처럼 화면을 보고 클릭하고 입력하는 쪽에 가깝습니다.

### PlayMCP와 카카오톡의 관계
PlayMCP는 카카오가 제공하는 MCP 기반 개방형 플랫폼입니다. 이 글을 읽을 때는 아래 두 층을 꼭 나눠 보는 편이 좋습니다.

| 구분 | 설치/연결 대상 | 할 수 있는 일의 성격 |
| --- | --- | --- |
| Kakao PlayMCP | `https://playmcp.kakao.com/mcp` 원격 MCP 서버 | PlayMCP 도구함에 담긴 도구를 Codex에서 호출 |
| KakaoTalk Computer Use | 카카오톡 데스크톱 앱 + Computer Use | 화면을 보고 클릭, 입력, 검색 |
| 카카오톡 공식 API | 별도의 개발자 API | 프로그램이 서버 기능과 직접 연동 |

즉, `https://playmcp.kakao.com/mcp`는 브라우저에서 읽는 웹페이지라기보다,
<strong>Codex 같은 MCP 클라이언트에 등록하는 서버 주소</strong>로 이해하는 편이 맞습니다.

## 3. 설치 전에 준비할 것

실습 전에 아래 다섯 가지를 준비하면 됩니다.

### 1) Codex Desktop / Codex App
Codex 앱에 ChatGPT 계정으로 로그인합니다.

### 2) Kakao PlayMCP 원격 MCP 서버
Codex에 아래 주소를 MCP 서버로 추가합니다.

```text
https://playmcp.kakao.com/mcp
```

권장 이름은 아래처럼 두면 관리가 쉽습니다.

```text
kakao_playmcp
```

### 3) Computer Use 플러그인
카카오톡 데스크톱 앱을 화면으로 조작하려면 Codex 앱 안에서 Computer Use 플러그인을 설치하고 활성화해야 합니다.

```text
Codex 앱
→ Settings
→ Computer Use
→ Install 또는 Enable
```

### 4) 카카오톡 데스크톱 앱
강의 실습은 macOS 기준으로 준비하는 편이 가장 안정적입니다.
실제 단체방보다 `나와의 채팅`이나 실습용 테스트방을 준비하는 것이 좋습니다.

### 5) macOS 권한 허용
Computer Use가 화면을 보고 클릭하려면 권한이 필요합니다.

필수 권한은 보통 아래 두 가지입니다.

- 화면 기록 권한
- 손쉬운 사용 권한

확인 위치는 보통 아래 흐름입니다.

```text
시스템 설정
→ 개인정보 보호 및 보안
→ 화면 기록
→ Codex 허용

시스템 설정
→ 개인정보 보호 및 보안
→ 손쉬운 사용
→ Codex 허용
```

## 4. 설치 순서

### 단계 1. Kakao PlayMCP 원격 MCP 추가
CLI를 쓸 수 있다면 아래처럼 추가할 수 있습니다.

```bash
codex mcp add kakao_playmcp --url https://playmcp.kakao.com/mcp
```

Codex 앱 설정 화면에서 넣는다면 보통 아래 값을 봅니다.

```text
이름: kakao_playmcp
URL: https://playmcp.kakao.com/mcp
transport: streamable_http
상태: enabled
```

설치 후에는 `~/.codex/config.toml`에 아래처럼 들어갈 수 있습니다.

```toml
[mcp_servers.kakao_playmcp]
url = "https://playmcp.kakao.com/mcp"
```

설치 확인은 아래처럼 해볼 수 있습니다.

```bash
codex mcp list
```

정상 등록되면 목록에 `kakao_playmcp`가 보입니다.

여기서 자주 나오는 상황이 하나 있습니다.
<strong>현재 열려 있는 Codex 세션에는 새 MCP 도구가 바로 안 뜰 수 있습니다.</strong>
이럴 때는 새 세션을 열거나 Codex를 재시작하는 편이 빠릅니다.

### 단계 2. PlayMCP 도구함 인증
PlayMCP는 카카오 계정 인증과 도구함 선택을 거쳐 써야 합니다.
실습 흐름은 보통 아래와 같습니다.

1. PlayMCP 사이트 접속
2. 카카오 계정 로그인
3. 사용할 도구를 도구함에 추가
4. Codex에서 `kakao_playmcp`를 통해 도구 사용 시도
5. 인증 요청이 뜨면 승인

즉, 주소만 등록했다고 끝나는 게 아니라,
<strong>도구함과 카카오 인증까지 이어져야 실제 도구가 보입니다.</strong>

### 단계 3. Codex 앱 설치 및 로그인
Codex 앱을 설치하고 ChatGPT 계정으로 로그인한 뒤, 기본 권한과 작업 폴더를 정리합니다.

### 단계 4. 카카오톡 데스크톱 설치
카카오톡을 설치하고 로그인합니다.
실습용 채팅방도 미리 준비해두면 좋습니다.

처음 따라 해볼 때는 실제 단체방보다 `나와의 채팅` 또는 실습용 단체방을 쓰는 편이 안전합니다.

### 단계 5. Computer Use 플러그인 활성화
- Codex 설정 열기
- `Computer Use` 찾기
- `Install`, `Enable` 또는 비슷한 버튼 누르기
- macOS 권한 요청이 나오면 허용하기
- Codex 재시작하기

### 단계 6. 카카오톡이 인식되는지 확인
카카오톡 앱을 먼저 열어 둔 뒤,
Codex에서 `@KakaoTalk` 또는 앱 선택 메뉴를 확인합니다.

보통 아래와 비슷한 이름이 보일 수 있습니다.

- `KakaoTalk`
- `KakaoTalk ComputerUse`
- 비슷한 변형 이름

표시 이름은 버전과 환경에 따라 조금 다를 수 있습니다.

## 5. 첫 실습은 안전하게 나눠서 진행하기

처음에는 PlayMCP 연결 확인과 카카오톡 화면 조작 확인을 나눠서 보는 편이 좋습니다.
그리고 가장 중요한 원칙은 이것입니다.

<strong>카카오톡 메시지는 절대 바로 전송하지 말고, 먼저 초안만 작성하게 한다.</strong>

### 실습 0. PlayMCP 연결 확인

```text
kakao_playmcp MCP 서버가 현재 Codex에서 사용 가능한지 확인해 주세요.
가능하다면 사용할 수 있는 도구의 종류를 초보자도 이해할 수 있게 설명해 주세요.
```

도구가 안 보이면 아래를 먼저 봅니다.

- `https://playmcp.kakao.com/mcp`가 MCP 서버로 추가됐는가
- 이름이 `kakao_playmcp`인가
- 새 세션을 열었는가 / 재시작했는가
- PlayMCP 도구함 인증이 끝났는가

### 실습 1. 앱 열기 확인

```text
@KakaoTalk 카카오톡 앱이 열려 있는지 확인하고, 현재 보이는 화면을 간단히 설명해 주세요.
```

### 실습 2. 읽지 않은 대화방 확인

```text
@KakaoTalk 읽지 않은 대화방이 있는지 확인해 주세요. 메시지 내용은 열지 말고 대화방 이름만 알려 주세요.
```

### 실습 3. 테스트 채팅방에 초안만 입력

```text
@KakaoTalk '나와의 채팅'을 열고 아래 문장을 입력창에 초안으로만 넣어 주세요. 아직 전송하지 마세요.

안녕하세요. Codex Computer Use 실습 메시지입니다.
```

### 실습 4. 전송 확인 후 보내기
전송은 사용자가 분명하게 지시한 뒤에만 갑니다.

```text
@KakaoTalk 지금 입력창에 있는 테스트 메시지를 나와의 채팅에 전송해 주세요.
```

## 6. 읽다가 바로 해보고 싶은 활용 예시

### 1) PlayMCP 도구함 확인

```text
kakao_playmcp에서 현재 사용할 수 있는 도구가 무엇인지 확인하고,
각 도구로 할 수 있는 일을 쉬운 한국어로 설명해 주세요.
```

이 예시는 MCP가 제대로 붙었는지 보여주고,
Computer Use 없이도 쓸 수 있는 기능이 무엇인지 구분하는 데 좋습니다.

### 2) 나와의 채팅방 관련 도구 확인

```text
kakao_playmcp 도구 중 카카오톡 나와의 채팅방과 관련된 도구가 있는지 확인해 주세요.
있다면 어떤 식으로 요청해야 하는지 예시 프롬프트를 만들어 주세요.
```

이건 PlayMCP 방식과 Computer Use 방식을 비교 설명할 때 좋습니다.

### 3) 최근 메시지 요약

```text
@KakaoTalk 실습방의 최근 메시지를 읽고 핵심 내용을 3줄로 요약해 주세요.
```

공지 요약, 대화 흐름 파악, 놓친 메시지 정리에 잘 맞습니다.
다만 민감한 방에서는 하지 않는 것이 좋습니다.

### 4) 답장 초안 만들기

```text
@KakaoTalk 실습방의 마지막 메시지에 대해 정중한 답장 초안을 작성해 주세요. 전송하지 말고 입력창에만 넣어 주세요.
```

### 5) 특정 단어 검색

```text
@KakaoTalk 현재 채팅방에서 '준비물'이라는 단어가 들어간 최근 메시지를 찾아 요약해 주세요.
```

준비물, 시간, 날짜 찾기 시연에 좋습니다.

### 6) 공지문을 Markdown으로 정리

```text
@KakaoTalk 실습방의 최근 공지 내용을 복사해서 제목, 날짜, 준비물, 할 일 순서의 Markdown으로 정리해 주세요.
```

단체방 공지 문서화, 회의록 초안 만들기 예시로 좋습니다.

### 7) 여러 방에 보내기 전 확인 흐름
이건 실제 외부 전송이므로 특히 조심해야 합니다.

```text
아래 안내문을 세 개 반 실습방에 보낼 예정입니다.
먼저 각 방 이름을 확인하고, 전송 직전에는 저에게 한 번씩 확인을 받아 주세요.

안내문:
내일 수업은 10시에 시작합니다. 노트북과 충전기를 준비해 주세요.
```

처음에는 여러 실제 단톡방보다 테스트방 2개 정도로만 좁혀 보는 편이 낫습니다.

## 7. Claude 예시를 Codex로 옮겨 보기

Claude와 Codex는 목적은 같아도 진입 경로가 다릅니다.

| 구분 | Claude에서의 흐름 | Codex에서의 흐름 |
| --- | --- | --- |
| 연결 이름 | Connector 또는 Integration | MCP server |
| 설정 위치 | Claude Settings → Customize → Connectors | Codex MCP 설정 또는 `codex mcp add` |
| PlayMCP 주소 | `https://playmcp.kakao.com/mcp` | `https://playmcp.kakao.com/mcp` |
| 인증 | Claude에서 Connect 후 카카오 인증 | Codex에서 MCP 호출 시 PlayMCP/카카오 인증 |
| 카카오톡 앱 조작 | PlayMCP 도구 중심 | PlayMCP 도구 + 필요하면 Computer Use |
| 메시지 보내기 | PlayMCP의 카카오톡 나와의 채팅방 도구 사용 | `kakao_playmcp` 도구함에 해당 도구가 있으면 사용 |

이 차이는 이렇게 읽으면 이해가 쉽습니다.

```text
Claude에서는 PlayMCP를 커넥터로 연결하고,
Codex에서는 같은 주소를 MCP 서버로 등록합니다.
주소는 같지만, 버튼 위치와 부르는 이름이 다릅니다.
```

### Codex에서 첫 메시지 보내기

```text
kakao_playmcp 도구함에 카카오톡 나와의 채팅방 메시지 보내기 도구가 있는지 확인해 주세요.
있다면 아래 메시지를 나에게 보내기 전에, 보낼 문장을 먼저 보여 주세요.

메시지:
안녕하세요. Codex PlayMCP 연동 테스트입니다.
```

확인 후 실제 전송은 이렇게 이어가면 됩니다.

```text
확인했습니다. 위 메시지를 카카오톡 나와의 채팅방으로 보내 주세요.
```

### Codex 활용 예시

#### 빠른 메모
```text
kakao_playmcp를 사용해서 아래 내용을 카카오톡 나와의 채팅방에 메모로 보내 주세요.
전송 전 최종 문장을 먼저 보여 주세요.

강의 아이디어: 카카오 PlayMCP 실습 10분 추가
```

#### 할 일 목록
```text
아래 할 일을 200자 이내로 정리해서 카카오톡 나와의 채팅방에 보내 주세요.
전송 전 내용 확인을 먼저 받아 주세요.

1. 강의자료 인쇄
2. 노트북 충전
3. 간식 준비
```

#### 대화 요약 저장
```text
지금까지 우리가 나눈 대화의 핵심을 3줄로 요약해 주세요.
```

## 8. 좋은 프롬프트 작성법

Computer Use는 화면을 직접 다루기 때문에 프롬프트를 구체적으로 쓰는 편이 안전합니다.

### 좋은 프롬프트의 조건
- 어떤 앱을 쓸지 말한다
- 어떤 채팅방을 열지 말한다
- 읽기만 할지, 입력만 할지, 전송까지 할지 구분한다
- 민감한 정보가 있으면 먼저 멈추게 한다
- 전송 전에는 항상 확인을 받게 한다

### 권장 문장

```text
전송하지 말고 초안만 작성해 주세요.
```

```text
민감한 개인정보가 보이면 내용을 읽지 말고 멈춰 주세요.
```

```text
마지막 전송 버튼을 누르기 전에 제 확인을 받아 주세요.
```

```text
현재 화면에서 보이는 범위 안에서만 작업해 주세요.
```

### 피해야 할 문장

```text
알아서 다 처리해 줘.
```

```text
모든 단톡방에 보내 줘.
```

```text
최근 대화를 전부 읽고 정리해 줘.
```

이런 문장은 범위가 너무 넓고 개인정보 노출 위험이 큽니다.

## 12. 자주 생기는 문제와 해결

### `kakao_playmcp`가 보이지 않을 때
1. MCP 서버 주소가 맞는지 확인
2. 이름이 `kakao_playmcp`인지 확인
3. `~/.codex/config.toml` 확인
4. 세션 재시작
5. PlayMCP 도구함 인증 확인

예시 설정은 아래처럼 볼 수 있습니다.

```toml
[mcp_servers.kakao_playmcp]
url = "https://playmcp.kakao.com/mcp"
```

### PlayMCP 주소를 브라우저에서 열었는데 안 보일 때
이 주소는 브라우저에서 읽는 안내 페이지가 아니라 MCP 서버 URL입니다. PlayMCP 사이트 설정은 `https://playmcp.kakao.com`에서 진행하고, Codex에는 MCP 서버 주소로 넣어야 합니다.

### `@KakaoTalk`이 안 보일 때
이 부분은 생각보다 자주 막히는 지점입니다. 그런데 실제로는 카카오톡 자체 문제라기보다, <strong>Codex가 현재 Mac의 카카오톡 앱을 아직 인식하지 못했거나 macOS 권한이 덜 열린 경우</strong>가 더 많습니다.

먼저 아래 순서대로 확인해 보면 좋습니다.

1. 카카오톡 데스크톱 앱이 실제로 실행 중인지 확인
2. 카카오톡 로그인이 되어 있고 채팅 목록 화면까지 열려 있는지 확인
3. Codex App을 완전히 종료했다가 다시 실행
4. Computer Use 플러그인이 실제로 활성화되어 있는지 확인
5. 화면 기록 / 손쉬운 사용 권한 확인
6. `@KakaoTalk`, `@카카오톡`, `@Kakao`를 모두 검색
7. 한글 입력 상태에서 잘 안 되면 영어 입력 상태로 다시 검색

짧게 다시 정리하면 이렇습니다.

- 카카오톡 앱 먼저 실행
- Codex 재시작
- Computer Use 설치 확인
- 화면 기록 / 손쉬운 사용 권한 확인
- 앱 목록에서 비슷한 이름 찾기
- PlayMCP와 Computer Use를 서로 다른 기능으로 구분하기

이 부분을 더 자세히 따라가고 싶다면 아래 별도 체크리스트 글을 함께 보면 됩니다.

- [Codex App에서 Computer Use로 KakaoTalk이 안 보일 때 먼저 볼 체크리스트](./2026-05-24-codex-computer-use-kakaotalk-checklist)

### Codex가 화면을 못 볼 때
보통은 화면 기록 권한 문제일 가능성이 큽니다.

```text

→ 개인정보 보호 및 보안
→ 화면 기록
```

```text
멈춰 주세요. 아무것도 입력하거나 전송하지 마세요.
```

## 15. 읽다 보면 자연스럽게 생기는 질문

### KakaoTalk 전용 스킬을 따로 설치해야 하나요?
두 가지를 구분해야 합니다.

- PlayMCP 방식: `https://playmcp.kakao.com/mcp` 원격 MCP 서버를 Codex에 추가
- 화면 조작 방식: Codex의 Computer Use 플러그인 사용

### `KakaoTalk ComputerUse`가 보이면 설치가 된 건가요?
대체로 그렇습니다. Codex가 카카오톡 앱을 화면 조작 대상으로 인식했다는 뜻입니다.

### `kakao_playmcp`가 보이면 설치가 된 건가요?
대체로 그렇습니다. 다만 현재 세션에 바로 안 뜰 수 있으니 새 세션이나 재시작이 필요할 수 있습니다.

### Windows에서도 되나요?
Codex 앱은 여러 환경에서 제공될 수 있지만, 강의 실습은 macOS 기준이 가장 안전합니다.

### 메시지를 자동으로 보내도 되나요?
기술적으로 가능할 수 있어도, 강의와 실무에서는 권장하지 않습니다. 먼저 초안을 만들고 사람이 확인한 뒤 보내는 흐름이 안전합니다.

### 카카오톡의 모든 대화 기록을 읽을 수 있나요?
아닙니다. 기본적으로 화면에 접근 가능한 범위와 검색·스크롤 가능한 범위 안에서 작업합니다.

### 개인정보는 안전한가요?
PlayMCP는 카카오 계정 인증과 도구함 선택에 따라 서비스 데이터와 연결될 수 있고, Computer Use는 화면에 보이는 내용을 처리 대상으로 삼을 수 있습니다. 그래서 처음에는 실습용 방을 쓰고, 민감한 화면은 피하는 것이 좋습니다.

3. 메시지 전송, 파일 업로드, 공유처럼 외부에 영향을 주는 작업은 반드시 사람이 마지막에 확인해야 합니다.
