# 2026년 5월 23일(토) Claude에서 Kakao PlayMCP 설치부터 카카오톡 메모 활용까지

어떤 날은 좋은 생각이 떠오르는 속도가 손보다 빠를 때가 있습니다.
메모 앱을 열기 전에 문장이 먼저 지나가고, 저장해두고 싶은 마음이 설명보다 먼저 앞설 때가 있습니다.

Claude에 Kakao PlayMCP를 연결하면, 바로 그 짧은 순간을 붙잡기가 조금 쉬워집니다.

- "카카오톡으로 오늘 할 일 메모해줘"
- "지금 대화 핵심만 3줄로 줄여서 카카오톡으로 보내줘"
- "좋은 문장 하나 카카오톡 나에게 보내기로 저장해줘"

이 글은 거창한 자동화 이야기보다 먼저, <strong>내 생각을 흘려보내지 않고 조용히 붙잡아두는 감각</strong>에서 시작합니다. 카카오톡 나에게 보내기를 작은 메모장처럼 쓰는 법을, 천천히 손에 익히는 쪽에 가깝습니다.

## 먼저 한 줄로 정리하면

```text
Claude에 PlayMCP를 연결하면,
Claude가 카카오톡 나에게 보내기 기능을 이용해 메모를 대신 보내줄 수 있습니다.
```

처음에는 이것만 이해해도 충분합니다.

## 1. 이 글로 할 수 있는 것

이번 글에서는 아래까지 다룹니다.

1. Claude 가입
2. Claude에서 PlayMCP 연결
3. 카카오 계정 로그인
4. 카카오톡 나에게 보내기 연결 확인
5. 첫 메시지 보내기
6. 메모, 할 일, 요약 활용 예시 익히기

즉, 설치만 설명하고 끝나는 글이 아니라 <strong>오늘 바로 써볼 수 있는 활용까지</strong> 이어집니다.

## 2. 이게 뭔지 아주 쉽게 이해해보자

### Claude는 뭐냐
Claude는 대화형 AI 서비스입니다.
글을 써주고, 요약해주고, 질문에 답해주고, 외부 도구와 연결되면 그 도구를 통해 실제 작업도 도와줄 수 있습니다.

4060미들스쿨 기준으로는 이렇게 이해하면 충분합니다.

> 글도 잘 쓰고, 정리도 잘하고, 내가 시키는 일을 조용히 도와주는 비서 같은 AI

### PlayMCP는 뭐냐
PlayMCP는 Claude 같은 AI가 카카오 서비스와 연결될 수 있게 해주는 연결 통로입니다.

비유하면,
Claude 혼자서는 카카오톡에 바로 손이 닿지 않는데,
PlayMCP를 붙이면 그 사이에 <strong>멀티탭 하나가 꽂힌 것처럼</strong> 외부 서비스 연결이 열립니다.

### MCP는 뭐냐
이건 너무 어렵게 볼 필요 없습니다.

> AI가 외부 도구와 대화할 수 있게 해주는 연결 규격

이 정도로만 이해해도 실습에는 충분합니다.

## 3. 전체 흐름은 이렇게 본다

이번 실습은 크게 네 단계입니다.

```text
Claude 가입
→ Claude에 PlayMCP 연결
→ 카카오 로그인 및 권한 허용
→ Claude에게 카카오톡 메모 보내기 요청
```

처음 하는 분도 이 순서만 기억하면 따라가기가 훨씬 쉽습니다.

## 4. STEP 1 — Claude 가입하기

먼저 `claude.ai`에 접속합니다.

- 구글에서 `클로드 AI`를 검색해도 되고
- 주소창에 직접 `claude.ai`를 넣어도 됩니다

그다음 회원가입을 합니다.

### 가장 쉬운 방법
- `Sign up` 클릭
- 구글 계정으로 계속하기
- 인증 완료

보통은 구글 계정으로 들어가는 쪽이 제일 덜 막힙니다.

무료 플랜으로도 시작할 수 있습니다.
다만 무료 플랜은 하루 사용량 제한이 있을 수 있습니다.

## 5. STEP 2 — Claude에서 PlayMCP 연결하기

여기가 실습의 핵심입니다.

예전에는 Connectors 메뉴를 따로 찾는 분이 많았는데,
현재는 Claude 쪽 UI가 바뀌어서 <strong>Customize 안에서 연결 도구를 보는 흐름</strong>으로 생각하는 게 편합니다.

### 들어가는 경로

- Claude 화면 왼쪽 아래 프로필 아이콘 클릭
- `Settings` 클릭
- `Customize` 탭 클릭

또는 아래 주소로 직접 들어가도 됩니다.

```text
https://claude.ai/customize
```

### PlayMCP 찾기
그다음에는

- `Add more integrations` 또는 `Browse integrations`
- 검색창에 `PlayMCP` 입력
- `PlayMCP` 항목 클릭

이 순서로 보면 됩니다.

### 연결하기
- `Connect` 또는 `Enable` 클릭
- 권한 요청이 뜨면 허용

정상 연결되면 PlayMCP 옆에 연결된 상태 표시가 뜹니다.

여기서 중요한 건, 메뉴 이름이 조금씩 바뀔 수는 있어도
<strong>Customize 안에서 integrations / connectors를 찾는 흐름 자체는 비슷하다</strong>는 점입니다.

## 6. STEP 3 — 카카오 계정 연결하기

다음으로 PlayMCP 쪽에서 카카오 로그인을 확인해야 합니다.

주소:

```text
https://playmcp.kakao.com
```

들어가서

- 카카오로 로그인
- 권한 허용
- 기본 연결 상태 확인

을 진행합니다.

처음 실습에서는 보통 아래 정도를 봅니다.

- 나에게 메시지 보내기
- 기본 정보 조회

여기서 4060미들스쿨 멤버들에게 꼭 말해두면 좋은 점이 하나 있습니다.

<strong>처음에는 다른 사람에게 보내기보다 `나에게 보내기`만 실습하는 것이 가장 안전합니다.</strong>

이렇게 해야 부담이 적고, 실수해도 범위가 작습니다.

## 7. STEP 4 — Claude에서 첫 메시지 보내기

이제 가장 쉬운 테스트를 해보면 됩니다.

Claude 대화창에 이렇게 말해보면 됩니다.

```text
카카오톡으로 "안녕하세요! PlayMCP 테스트 성공!" 보내줘
```

정상 동작하면,
Claude가 메시지 전송 성공을 알려주고,
카카오톡 `나에게 보내기` 쪽에 문장이 들어옵니다.

처음 성공 경험은 가능한 한 짧은 문장으로 하는 게 좋습니다.

## 8. 처음 써볼 때 좋은 활용 예시

### 1) 빠른 메모
강의하다가 생각이 떠올랐을 때 가장 쓸 만합니다.

예:

```text
카카오톡으로 "강의 아이디어: 카카오 자동화 실습 10분 추가" 메모해줘
```

이건 실제로 메모 앱 여는 것보다 빨리 끝나는 경우가 많습니다.

### 2) 할 일 목록 정리
예:

```text
카카오톡으로 오늘 할 일 메모해줘.
강의자료 인쇄, 노트북 충전, 간식 준비
```

이렇게 하면 Claude가 보기 좋게 짧게 정리해 보낼 수 있습니다.

### 3) 대화 요약 보내기
Claude와 길게 이야기한 뒤 핵심만 남기고 싶을 때 좋습니다.

예:

```text
지금까지 우리가 나눈 대화 핵심 3줄로 요약해서 카카오톡으로 보내줘
```

이건 4060미들스쿨처럼 배운 내용을 바로 남겨두고 싶은 흐름과 잘 맞습니다.

### 4) 좋은 문장 저장
예:

```text
카카오톡으로 메모해줘.
파인만 기법: 모르는 것을 아이에게 설명할 수 있을 때 진짜 아는 것이다.
```

좋은 문장을 흘려보내지 않고 남겨두는 데 좋습니다.

### 5) 오늘 목표 보내기
예:

```text
오늘 목표를 카카오톡으로 보내줘.
강의 준비 완성, 책 1챕터 쓰기, 저녁 산책
```

하루 시작 전에 자기 자신에게 보내는 용도로 잘 맞습니다.

### 6) 긴 글이나 뉴스 요약해서 보내기
예:

```text
이 글 핵심만 짧게 요약해서 카카오톡으로 보내줘: [내용 붙여넣기]
```

긴 내용을 그대로 보내기보다,
<strong>짧게 줄여서 보내는 습관</strong>이 실제로 더 유용합니다.

## 9. 200자 제한은 어떻게 생각하면 좋나

처음 쓸 때 가장 많이 나오는 질문이 이겁니다.

"길면 어떻게 되나요?"

실습 기준으로는 이렇게 이해하면 됩니다.

- 너무 긴 내용은 짧게 요약해서 보내게 한다
- 처음부터 `200자 안으로 줄여서 보내줘`라고 말하면 더 안정적이다

즉, Claude에게 메시지를 만들게 할 때는
<strong>짧고 또렷한 메모</strong> 쪽으로 유도하는 게 좋습니다.

## 10. 이 기능을 너무 거창하게 설명하지 않는 편이 좋다

4060미들스쿨 글에서는 이 기능을 대단한 자동화처럼 부풀리기보다, 생활 속에서 바로 붙는 장면으로 보여주는 편이 훨씬 잘 들어갑니다.

- 좋은 아이디어가 떠오를 때 바로 메모로 남길 수 있다
- 긴 대화를 요약해서 나에게 다시 보낼 수 있다
- 할 일 목록을 스스로에게 보내는 데 쓸 수 있다
- 글이나 강의 내용을 핵심만 추려 저장할 수 있다

즉,
<strong>자동화 쇼보다 생활형 메모 습관</strong>으로 보여주는 편이 훨씬 설득력이 있습니다.

## 11. 자주 묻는 질문

### 다른 사람에게도 보낼 수 있나
처음에는 `나에게 보내기` 기준으로 보는 게 가장 안전합니다.
범위를 좁혀두면 부담도 적고, 실수할 여지도 훨씬 줄어듭니다.

### 무료로 쓸 수 있나
보통은 Claude 무료 플랜과 PlayMCP 기본 기능으로 시작할 수 있습니다.
다만 Claude는 사용량 제한이 있을 수 있습니다.

### 카카오 연결이 잘 안 될 때는
아래 순서로 보는 편이 좋습니다.

1. Claude Customize 안에서 PlayMCP가 연결 상태인지 보기
2. `playmcp.kakao.com`에서 카카오 로그인 상태 확인
3. 브라우저 새로고침 후 다시 시도
4. 필요하면 연결 해제 후 재연결

### 개인정보가 넘어가는 게 걱정될 때는
처음에는 민감한 대화보다
- 메모
- 할 일
- 요약
정도의 가벼운 내용부터 시작하는 게 좋습니다.

## 12. 바로 해보면 좋은 것


```text

```

### 미션 3. 내 활용 장면 찾기
아래 세 가지를 직접 떠올려보면 좋습니다.

1. 언제 메모가 필요할까
2. 언제 할 일을 스스로에게 보내고 싶을까
3. 어떤 대화를 요약해 저장하면 도움이 될까

## 13. 바로 붙여 쓰는 문장 모음

```text
카카오톡으로 오늘 할 일 보내줘: [항목1], [항목2], [항목3]
```

```text
지금까지 대화 핵심 3줄로 요약해서 카카오톡으로 보내줘
```

### 글 요약
```text
이 내용 핵심만 요약해서 카카오톡으로 보내줘: [내용 붙여넣기]
```

### 아이디어 저장
```text
카카오톡으로 아이디어 저장해줘: [아이디어 내용]
```

### 목표 정리
```text
오늘 목표를 카카오톡으로 보내줘: [목표1], [목표2]
```
