# 2026년 5월 24일(일) Codex App에서 Computer Use로 KakaoTalk이 안 보일 때 먼저 볼 체크리스트

Codex App에 Computer Use 플러그인을 설치했고, 카카오톡 데스크톱도 이미 설치했는데 막상 `@`로 앱을 찾으려고 하면 KakaoTalk이 안 보일 때가 있습니다.

이럴 때 많은 분들이 바로 이렇게 생각합니다.

"카카오톡이 이상한가?"

그런데 실제로는 카카오톡 자체 문제라기보다, <strong>Codex가 현재 Mac 안의 카카오톡 앱을 아직 제대로 인식하지 못했거나, macOS 권한이 부족한 경우</strong>가 더 많습니다.

그래서 이번 글은 원인을 크게 어렵게 설명하기보다,
<strong>어디부터 어떤 순서로 확인하면 되는지</strong>를 차근차근 짚어보는 체크리스트 형태로 정리해보겠습니다.

## 먼저 한 줄로 정리하면

> 한글 설정 자체보다, 카카오톡 실행 상태, Codex 재시작 여부, macOS 권한, 앱 이름 검색 방식이 더 중요한 원인인 경우가 많습니다.

이 한 줄만 먼저 잡고 들어가면 훨씬 덜 헷갈립니다.

## 1. 가장 먼저, 카카오톡 데스크톱 앱이 실제로 실행 중인지 보세요

제일 먼저 확인할 것은 아주 단순합니다.

<strong>카카오톡 앱이 실제로 켜져 있는가?</strong>

Computer Use는 화면에 떠 있는 앱을 보고 조작하는 쪽에 가깝기 때문에,
앱이 꺼져 있거나 로그인 전 상태이면 Codex가 앱을 후보로 잘 잡지 못할 수 있습니다.

### 확인할 것

- 카카오톡 데스크톱 앱이 설치되어 있는가
- 카카오톡 로그인이 되어 있는가
- 채팅 목록 화면까지 열려 있는가

쉽게 말하면,
문이 잠겨 있거나 아직 현관도 안 연 상태인데
밖에서 "저 집 안에 들어가서 일해줘"라고 하는 것과 비슷합니다.

앱이 켜져 있고,
실제로 채팅 목록 화면까지 올라와 있어야 인식이 훨씬 잘 됩니다.

## 2. Codex App을 완전히 종료했다가 다시 실행해 보세요

Computer Use 플러그인을 방금 설치한 직후에는,
기존 Codex 세션이 그 변화를 바로 반영하지 못하는 경우가 있습니다.

그래서 설치는 끝났는데도 `@KakaoTalk`이 안 보일 수 있습니다.

### 권장 순서

1. Codex App 완전 종료
2. 카카오톡 데스크톱 실행
3. Codex App 다시 실행
4. 새 대화 시작
5. `@KakaoTalk` 또는 `@카카오톡` 검색

이건 생각보다 자주 먹히는 해결책입니다.

즉,
설치는 되었지만 세션이 예전 상태를 잡고 있을 수 있으니,
<strong>한 번 완전히 끊고 다시 시작해 주는 것</strong>이 좋습니다.

## 3. macOS 권한이 빠져 있지 않은지 꼭 확인하세요

Computer Use는 단순 텍스트 기능이 아닙니다.
화면을 보고, 클릭하고, 입력하는 기능이기 때문에 macOS 권한이 꽤 중요합니다.

특히 아래 두 가지 권한이 핵심입니다.

- 화면 기록
- 손쉬운 사용

### 확인 위치

```text
시스템 설정
→ 개인정보 보호 및 보안
→ 화면 기록
→ Codex 또는 Codex Computer Use 허용
```

그리고 다시:

```text
시스템 설정
→ 개인정보 보호 및 보안
→ 손쉬운 사용
→ Codex 또는 Codex Computer Use 허용
```

권한을 바꾼 뒤에는 바로 끝내지 말고,
<strong>Codex App을 다시 시작</strong>하는 편이 좋습니다.

쉽게 비유하면,
사람을 사무실로 들여보냈는데
불은 꺼져 있고, 문도 잠겨 있고, 서랍도 못 열게 한 상태와 비슷합니다.

권한이 빠지면 앱이 보여도 제대로 못 움직입니다.

## 4. `@KakaoTalk`과 `@카카오톡`을 둘 다 검색해 보세요

한글 환경이라고 해서 무조건 문제인 것은 아닙니다.
다만 `@` 검색에서 표시 이름이 다르게 보일 수는 있습니다.

그래서 아래처럼 몇 가지를 다 시도해 보는 편이 좋습니다.

### 검색해 볼 이름

- `@KakaoTalk`
- `@카카오톡`
- `@Kakao`

카카오톡 화면은 한글로 보여도,
내부 앱 이름이나 검색 후보는 `KakaoTalk`처럼 영어 이름으로 잡힐 때가 있습니다.

즉,
보이는 언어와 <strong>찾히는 이름이 항상 같지는 않다</strong>고 보면 됩니다.

## 5. 영어 입력 상태에서 다시 검색해 보세요

의외로 여기서 풀리는 경우도 있습니다.

한글 입력 상태에서는 `@` 검색이 매끄럽지 않거나,
후보 매칭이 어색하게 되는 경우가 있습니다.

### 해볼 것

- 입력기를 영어로 전환
- `@KakaoTalk` 입력
- 목록에 `KakaoTalk` 또는 비슷한 이름이 보이는지 확인

이건 설정 문제라기보다,
검색 입력 과정이 한글 조합 상태에서 조금 덜 안정적인 경우를 피하는 쪽에 가깝습니다.

## 6. PlayMCP와 Computer Use를 서로 다른 것으로 구분해서 보세요

여기서 정말 많이 헷갈립니다.

`https://playmcp.kakao.com/mcp`를 Codex에 연결하는 것은 <strong>Kakao PlayMCP 원격 MCP 연결</strong>입니다.

반면 `@KakaoTalk`은 <strong>내 Mac에 설치된 카카오톡 앱을 Computer Use가 화면으로 보고 조작하는 기능</strong>입니다.

즉, 둘은 비슷해 보여도 같은 것이 아닙니다.

### 다시 아주 짧게 정리하면

- Kakao PlayMCP = 원격 MCP 서버 연결
- `@KakaoTalk` Computer Use = 내 컴퓨터 카카오톡 앱 화면 조작

그래서 PlayMCP를 설치했다고 해서,
자동으로 `@KakaoTalk`이 목록에 뜨는 것은 아닙니다.

이 부분이 섞이면 실습이 갑자기 어려워집니다.

## 7. 그래도 안 보이면 Codex에게 이렇게 물어보세요

여기까지 했는데도 안 보이면,
무작정 다시 설치하기보다 Codex에게 현재 인식 상태를 먼저 확인하게 하는 편이 좋습니다.

예를 들어 이렇게 말해볼 수 있습니다.

```text
Computer Use로 현재 Mac에서 사용할 수 있는 앱 목록을 확인하고,
KakaoTalk 앱이 보이는지 찾아 주세요.
```

또는:

```text
KakaoTalk 앱을 Computer Use로 열 수 있는지 확인해 주세요.
```

즉,
"왜 안 되지"만 반복하기보다
<strong>지금 Codex가 무엇을 보고 있는지부터 확인</strong>하는 것이 더 빠른 경우가 많습니다.

## 8. 최종 점검 순서를 한 번에 모아보면

아래 순서대로 보면 대부분의 막힘은 어느 정도 정리됩니다.

1. 카카오톡 데스크톱 앱 설치
2. 카카오톡 실행 및 로그인
3. 채팅 목록 화면 열기
4. Codex App에서 Computer Use 플러그인 활성화
5. macOS 화면 기록 권한 허용
6. macOS 손쉬운 사용 권한 허용
7. Codex App 완전 종료 후 재실행
8. 새 대화에서 `@KakaoTalk` 또는 `@카카오톡` 검색

이 순서는 그냥 체크리스트처럼 하나씩 따라가면 됩니다.

## 어려운 말을 생활 비유로 바꾸면

### Computer Use
AI가 컴퓨터 안의 앱을 직접 눌러보는 <strong>원격 손</strong> 같은 것입니다.
그냥 텍스트로 아는 것이 아니라, 화면을 보고 클릭하고 입력하는 쪽입니다.

### 화면 기록 권한
앱 화면을 볼 수 있는 허가입니다.
이 권한이 없으면, 눈을 가린 채 일하라는 것과 비슷합니다.

### 손쉬운 사용 권한
클릭하고 입력할 수 있는 허가입니다.
이 권한이 없으면, 화면은 봐도 손을 못 쓰는 상태에 가깝습니다.

### PlayMCP
카카오가 준비한 원격 도구함을 Codex에 연결하는 느낌입니다.
카카오톡 화면을 직접 누르는 것과는 다릅니다.

## 한 번 더 짧게 복습하면

- KakaoTalk이 안 보인다고 해서 바로 카카오톡 문제로 볼 필요는 없다
- 먼저 카카오톡 실행 상태와 로그인 상태를 확인한다
- 그다음 Codex App을 완전히 껐다가 다시 켠다
- macOS 권한 두 가지를 꼭 확인한다
- `@KakaoTalk`, `@카카오톡`, `@Kakao`를 모두 시도해 본다
- PlayMCP와 Computer Use는 서로 다른 기능으로 구분해 이해한다

즉,
<strong>대부분은 복잡한 버그보다 실행 상태와 권한, 재시작, 검색 방식에서 풀리는 문제</strong>라고 보면 됩니다.

## 마무리

카카오톡이 안 보일 때 사람 마음은 금방 조급해집니다.
설치를 잘못했나 싶고, 한글 설정 때문인가 싶고, 카카오 자체가 막혀 있나 싶기도 합니다.

그런데 실제로는 꽤 많은 문제가 이 네 가지 안에서 정리됩니다.

- 앱이 켜져 있는가
- Codex를 다시 시작했는가
- macOS 권한이 열려 있는가
- 앱 이름을 여러 방식으로 검색했는가

이 네 가지만 차분히 확인해도,
대부분의 첫 막힘은 생각보다 빨리 넘어갑니다.

처음엔 조금 번거로워 보여도,
한 번만 감을 잡아두면 다음부터는 훨씬 덜 막히게 됩니다.
