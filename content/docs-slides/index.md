# 문서 · 슬라이드

문서와 슬라이드는 내용만 맞아서는 부족합니다. 읽는 사람이 바로 이해하고, 다시 쓰는 사람이 구조를 잃지 않으며, 자동화가 붙어도 품질이 흔들리지 않아야 합니다.
