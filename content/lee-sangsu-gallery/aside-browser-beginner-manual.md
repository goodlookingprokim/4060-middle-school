# Aside Browser 완전초보 입문 매뉴얼북

이 자료는 이상수님이 보내주신 원문 HTML 입문 매뉴얼을 그대로 보존한 것입니다.
만든 분이 의도한 화면 그대로 보실 수 있게 전체 화면으로 열립니다.
